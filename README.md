# Turbo Karts 🏎️

Petit jeu de course en 2D dans le navigateur (HTML5 Canvas, JavaScript, Bootstrap)
avec classement des scores en PHP/MySQL.

## Installation locale
1. Installer Laragon et démarrer Apache + MySQL
2. Copier le projet dans `C:\laragon\www\kartgame`
3. Créer une base `kartgame` et importer `database.sql`
4. Ouvrir http://localhost/kartgame/
